---
name: eli5
description: Re-explains the last explanation, or a named topic, more simply, for someone new to the area. Use when the user runs /eli5, says "explain like I'm 5", "simpler", or "I don't follow".
---

Explain again, more simply. Assume I do not know this area at all. The last explanation lost me because it assumed background I do not have.

Explain $ARGUMENTS if given. Otherwise, explain the last thing you explained to me.

- **Start from zero.** First say what the thing is and why it exists, in everyday words. Only then say how it fits what we are doing.
- **Rebuild, do not shrink.** Do not repeat the last answer with smaller words. Find the idea that the rest depends on and start there.
- **No unexplained terms.** Use a plain word instead. If a term is unavoidable, define it in the same sentence.
- **One analogy at most.** Pick something from daily life. Say where it stops being true.
- **Keep it short.** A few short paragraphs. No code, tables or option lists unless I ask.
- **Stay correct.** If simplifying leaves out something that matters, name it in one line at the end.

End with one line offering the next layer of detail.
